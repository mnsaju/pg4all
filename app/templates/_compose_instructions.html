Expects `credential` (for build_id) plus `has_compose`/`has_pgbackrest`/ `has_pgadmin`/`pgadmin_email` — computed by checking build_output// on disk, not stored on the credential record, since the build artifacts themselves are just as durable as the encrypted credential store. #} {% if has_compose %}

Companion services were included in this build. Start Postgres and all of them together from the generated compose file:

cd build_output/{{ credential.build_id }} docker compose up -d
{% endif %} {% if has_pgadmin %}

pgAdmin is bound to 127.0.0.1 only on port 5050 — it is never published to the network, so reach it over an SSH tunnel to the host, not directly:

ssh -L 5050:127.0.0.1:5050 <host> # then open http://localhost:5050 pgAdmin login: {{ pgadmin_email }} pgAdmin password: (same as the superuser password above)

Add the Postgres connection yourself the first time you open it — host postgres, port 5432, same username/password. pg4all doesn't pre-seed it.

{% endif %} {% if has_pgbackrest %}

pgBackRest is installed in the image with stanza main (/etc/pgbackrest/pgbackrest.conf). Mount a volume at /var/lib/pgbackrest for the backup repository, then run the stanza creation once and back up whenever you want — pg4all doesn't schedule this for you:

docker exec <container> pgbackrest --stanza=main stanza-create docker exec <container> pgbackrest --stanza=main backup
{% endif %}
